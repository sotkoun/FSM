\# VHDL Finite State Machines (FSM)



This repository contains educational implementations of Finite State Machines (FSM) in VHDL. The code was designed and simulated using Xilinx Vivado.



\## Repository Structure

The repository contains two separate exercises, organized into the following subdirectories:



\* 📂 \*\*`parking/`\*\*: Implementation of a parking lot control system using an FSM. It includes managing vehicle entries/exits and capacity control.

\* 📂 \*\*`Pattern\_Detector/`\*\*: Implementation of a digital sequence detector (Mealy machine). It continuously searches for the serial sequences `"001"` and `"110"`.



Each subdirectory contains its own VHDL files (RTL code and testbenches), Tcl scripts for easy project reconstruction in Vivado, and more detailed README files.
